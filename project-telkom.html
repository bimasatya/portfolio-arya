Dashboard Monitoring Proyek Telkom

Proyek ini bertujuan untuk meningkatkan monitoring dan visibilitas status proyek jaringan di tingkat distrik menggunakan dashboard berbasis data.

Problem

Monitoring proyek sebelumnya tidak terstruktur dan sulit dilacak secara real-time, sehingga menghambat pengambilan keputusan operasional.

Solution

Membangun dashboard funneling yang menampilkan status proyek seperti PS, Cancel, dan Work untuk memudahkan tracking dan evaluasi performa teknisi.

Process

  • Data collection dari sistem internal
  • Data cleaning menggunakan Excel & Python
  • Visualisasi menggunakan dashboard
  • Validasi data melalui uji petik lapangan

Result

Dashboard berhasil membantu monitoring proyek secara real-time dan meningkatkan efektivitas pengambilan keputusan di tingkat operasional.
