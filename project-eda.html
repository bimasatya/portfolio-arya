Exploratory Data Analysis: Sosial Ekonomi Jawa Timur

Project ini berfokus pada analisis data sosial ekonomi di Jawa Timur menggunakan pendekatan Exploratory Data Analysis (EDA) dan visualisasi interaktif untuk menghasilkan insight yang dapat mendukung pengambilan kebijakan.

Problem

Data sosial ekonomi sering kali memiliki banyak variabel dan kompleksitas tinggi, sehingga sulit dipahami secara langsung tanpa visualisasi yang tepat.

Objective

Mengidentifikasi pola dan hubungan dalam data sosial ekonomi untuk memberikan insight yang relevan terkait kondisi masyarakat, seperti kemiskinan dan tenaga kerja.

Solution

Melakukan Exploratory Data Analysis (EDA) dan membangun dashboard interaktif menggunakan Tableau untuk memvisualisasikan data secara informatif.

Process

  • Pengumpulan dan pemahaman dataset sosial ekonomi
  • Data cleaning dan preprocessing
  • Exploratory Data Analysis (EDA)
  • Pembuatan visualisasi menggunakan Tableau
  • Interpretasi hasil analisis

Tools & Technologies

Python (Pandas, Matplotlib), Tableau, Excel

Result

Berhasil mengidentifikasi pola penting dalam data sosial ekonomi, seperti distribusi kemiskinan dan kondisi tenaga kerja di berbagai wilayah Jawa Timur.

Impact

Insight yang dihasilkan dapat digunakan sebagai dasar dalam pengambilan kebijakan dan perencanaan pembangunan berbasis data.
