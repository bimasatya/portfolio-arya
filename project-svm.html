Sentiment Analysis of Customer Reviews using SVM

Project ini bertujuan untuk menganalisis sentimen pelanggan berdasarkan data ulasan bisnis menggunakan pendekatan Machine Learning, khususnya algoritma Support Vector Machine (SVM).

Problem

Banyaknya ulasan pelanggan dalam jumlah besar membuat proses analisis secara manual menjadi tidak efisien dan sulit untuk mendapatkan insight secara cepat.

Objective

Membangun model klasifikasi sentimen untuk mengidentifikasi opini pelanggan menjadi kategori positif dan negatif secara otomatis.

Solution

Menggunakan algoritma Support Vector Machine (SVM) untuk melakukan klasifikasi sentimen berbasis teks, dengan pipeline preprocessing dan feature extraction.

Process

  • Data cleaning (case folding, tokenization, stopword removal)
  • Text preprocessing menggunakan NLTK
  • Feature extraction menggunakan TF-IDF
  • Model training menggunakan SVM
  • Evaluasi model (accuracy & confusion matrix)

Tools & Technologies

Python, Scikit-learn, Pandas, NLTK, TF-IDF Vectorizer

Result

Model berhasil mencapai akurasi sekitar ±89% dalam mengklasifikasikan sentimen ulasan pelanggan, sehingga dapat digunakan sebagai dasar analisis kepuasan pelanggan.

Impact

Hasil analisis membantu memahami persepsi pelanggan terhadap layanan, serta memberikan insight yang dapat digunakan untuk meningkatkan kualitas bisnis.
